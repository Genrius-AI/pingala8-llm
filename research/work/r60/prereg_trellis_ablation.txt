2. EQUAL BYTES (lemma + gates in the script)
 Blob length = side_bytes(rows, n) + sum over (row, 256-col block) of 8 NW[c], NW = W1 + W2 + W3 of the block's class
 (r48k.py:143-147, :149-162 asserts it); no term depends on tr, NS or the tables. The rate-off class depends only on the byte budget
 8 (base - MARGIN - side_bytes) (cs_build_q.py:169-171, r52a_k.py:59-63). Native VR3 tensor = 2064 + 64 nt + 256 nt NW[c] B
 (cs_qnative.py:46): A|B|c|NS|TRL|tag header of fixed size. Only data-dependent bytes: clamp-delta side tensors, 8 B per entry
 (B4: 561 entries, 4,488 B; logs/cs_qfull.log DELTA).
 G1: each of the 252 blobs has the size of B4's blob of the same name (work/csq/f1o/blobs_roff); total 972,043,712 B. Hard gate.
 G2: native total within +/- 64 KB of B4's 1,243,153,792 B (prediction; the script warns above 256 KB).
